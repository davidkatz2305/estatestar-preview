Hinweise zur Testseite

Stand: 18.10.2026. Diese Hinweise beschreiben die Technik der Designvorschau. Anbieter- und Kontaktangaben finden Sie im Impressum von ESTATESTAR.

Hosting

Diese Vorschau wird über GitHub Pages bereitgestellt. GitHub verarbeitet beim Aufruf unter anderem die IP-Adresse für Betrieb und Sicherheit. Datenschutzhinweise von GitHub.

Bilder, Filme und Schriften

Die Vorschau lädt ihre Bilder, Schriften und Filme vom selben GitHub-Pages-Projekt. Die Website setzt selbst keine Analyse-Tracker und speichert keine Angaben in Cookies oder im lokalen Browserspeicher. Der Hintergrundfilm lässt sich pausieren.

Virtuelle Rundgänge

Erst beim Klick auf „Rundgang starten“ wird eine externe Tour eingebettet. Dabei wird eine Verbindung zu Matterport oder MPskin hergestellt; diese Dienste können eigene Datenverarbeitungen und Speichermechanismen einsetzen. Es gelten die Informationen des jeweiligen Anbieters. Ohne diesen Klick wird keine Tour eingebettet.

Kontakt

E-Mail- und Telefonlinks öffnen die entsprechende Anwendung auf Ihrem Gerät. Die Vorschau besitzt kein Kontaktformular, das Daten an einen eigenen Server übermittelt. Ein Klick auf „E-Mail vorbereiten“ versendet noch keine Nachricht.

Vor einer dauerhaften produktiven Veröffentlichung müssen die vollständigen Datenschutzhinweise auf den dann eingesetzten Betrieb und die verantwortliche Stelle abgestimmt werden.
